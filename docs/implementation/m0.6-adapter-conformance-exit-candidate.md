## Purpose

This document records the completed M0.6 milestone exit audit. The exact Phase 5 candidate was challenged against the accepted architecture, compatibility, transport, conformance, lifecycle, provenance, replay, solver-independence, and public-interface boundaries before final merge.

## Reviewed milestone scope

M0.6 provides reusable Core-side tooling for external adapter projects to demonstrate conformance with published Adapter Protocol 0.1 / Public Contract 0.1 behavior while preserving these boundaries:

- conformance is interoperability evidence, not solver-native physical/numerical validation;
- conformance results are distinct from SOL lifecycle/evaluation classification;
- adapter implementations are observed through the published transport boundary rather than linked into Core;
- ProtocolFailure, valid negative responses, transport/harness failure, and lifecycle state remain distinct;
- execute response loss grants no automatic replay authority;
- backend-native identifiers remain opaque provenance rather than canonical semantic identity;
- exact conformance CLI spelling, exit codes, environment-variable names, profile controls, and stable serialized report output remain provisional unless separately approved as a public interface.

## Phase 5 external-project evidence

`examples/external-project-conformance/` is a nested standalone Cargo workspace. Its manifest depends on conformance libraries only and does not link the reference adapter implementation, MockAdapter implementation, or a solver runtime.

Rust Core CI supplies executable paths for the reference adapter and the adversarial probes. The consumer invokes them using `ExternalAdapterCommand`, so adapter behavior crosses the JSON-RPC/stdin-stdout process boundary before becoming conformance evidence.

The fixture directory is copied into the CI runner temporary directory before the standalone workflow runs. The consumer therefore demonstrates runtime reuse of the published versioned fixture material through an explicit path rather than a Core-relative fixture assumption.
